# Contributing

- Open an issue for a fit, assembly or wiring problem. Include the component model and revision, the Blender scene, and any measurements or photos that show the problem.
- For design changes, edit the Blender generator or `wiring.csv`, regenerate both scenes and the contact CSV, and check both camera views. Include the updated previews when the visible design changes.
- If a change affects tolerances, wire routing or the hinge, describe how you checked the result and whether the check used a physical prototype.
- Document the source, author, licence and changes for any imported CAD. Submit Moby design changes under [CERN-OHL-P-2.0](LICENSE).
